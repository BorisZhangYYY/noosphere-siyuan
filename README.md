# 知流 · ZhiLiu for SiYuan

[English](.docs/README.en.md)

在思源笔记中抓取网页文章，按需进行 AI 审阅和原生编辑，再保存正文、来源信息与图片。

## 可以做什么

- **抓取文章**：输入公开网页链接，获取正文、图片和可用的作者、发布时间等来源信息。
- **审阅与编辑**：可跳过 AI 保留抓取原文，也可选择审阅视角、输出语言和文章格式；在知流弹窗内使用思源原生块编辑器整理正文。
- **管理配图**：可选识图模型给出移除建议，保存前可人工恢复或移除；保存时自动尝试将图片下载到思源资源目录，失败则保留原链接。
- **保留来源**：来源链接、作者、发布时间和抓取时间分行展示，随正文保存；旧文章只能恢复记录时间时会明确标注。
- **查看历史**：抓取原文、处理稿、图片取舍和保存位置随文章保留，可搜索、继续处理或删除记录。
- **保存为思源内容**：保存到空白未命名文档时设置真正的文档标题；保存到已有文档时追加文章，不覆盖原有内容。

微信公众号文章会补全可识别的作者与发布时间、清理阅读器和留言等页面文案；小黑盒新旧分享链接会整理为正文地址，并清理或补全标题，识别到网页作者卡片时补全来源、清理评论与推荐；知乎返回登录或验证页面时会提示抓取失败。

## 开始使用

![知流工作台：顶部抓取链接、左侧正文编辑、右侧 AI 审阅与素材、右下保存位置](https://raw.githubusercontent.com/BorisZhangYYY/noosphere-siyuan/main/.docs/images/workbench.png)

上方用于抓取新文章，左侧阅读与编辑正文，右侧的 AI 审阅、素材和保存位置统一滚动。点击右上角“设置”配置服务。

1. 安装并启用插件，点击思源顶部的地球图标打开知流。
2. 在“设置”中填写 Firecrawl API Key；需要 AI 审阅时，再配置文字模型和可选的识图模型。
3. 在顶部粘贴网页链接并点击“抓取文章”。左侧查看正文，点击“编辑”可直接修改，完成后点击“确定”。
4. 按需在右侧选择审阅视角和输出语言，再点击“AI 审阅”；在“素材”中点击缩略图查看配图，勾选需要移除的图片。
5. 从思源文档菜单复制目标**文档 ID**，填入右下方“保存位置”，点击“保存文章”。保存后可点击“打开文档”查看。
6. 也可以在“分类配置”中填写分类根目录（**笔记本 ID 或根文档 ID**），保存设置后，在文章页切到“自动分类”。文章页隐藏位置字段，根目录只在“分类配置”修改；切换历史文章也不会恢复旧根目录或目录开关。正文和图片审阅全部完成后，会自动选择根目录下的已有分类并保存，无需再点“保存文章”。取消或审阅失败时不会自动保存；保存失败则保留审阅稿，可点击“保存文章”重试。

### 分类文档准备

- 在“分类配置”中填好根目录后，在下方“分类管理”点击“新增分类”，在弹窗中填写分类名称、父分类和描述，再点击“新建并同步”，就会在思源中建立分类文档。已有分类可在同一窗口编辑名称和描述，或直接打开对应文档。
- 描述可以手动填写，也可以点击“AI 生成描述”。AI 只填写表单，确认同步前不会创建或修改文档。生成时只参考当前分类名称和父级路径，专注本类主题、内容范围和典型文章，不附加其他分类的比较、排除或转存建议。
- 根文档直接维护“目录”和“说明”两个二级标题，目录随分类变化自动更新。“分类位置”的根目录输入框旁提供“打开根文档”，直接打开当前填写的位置。启用思源“顶层笔记本文档”时，选定笔记本也会直接使用其根文档；旧版或未启用时仍可按笔记本分类，不创建额外总览文档。分类配置入口位于工作台页签最右侧，带 AI 标识，独立于模型设置。
- 新分类自带 `## 分类描述` 和 `## 文章目录`。打开管理窗口时，旧分类的孤立介绍会补上描述标题；目录和其他章节保留。描述以思源正文为准，直接在思源修改后，下次分类就会读取新内容。
- 把“文章目录”改为“目录”不影响分类。分类依据是分类名称、完整路径和描述区域，自动目录靠内部标记识别；描述标题改名也可继续定位已登记的区域。修改描述会改变分类规则，删除分类文档或分类标记会让它退出候选。
- 如果已有分类文档，也可在其属性中添加 `custom-zl-category`（值任意，非空即可）。未整理的旧文档仍兼容首个介绍段落与 `custom-zl-desc`；进入分类管理后会把描述同步到正文区域。
- 在“分类配置”中勾选“自动创建并维护分类目录”，首次保存到分类时会在介绍下面添加目录块。右栏的来源、审阅、素材和保存位置共用一个滚动区，素材默认折叠且保留各审阅状态的数量。
- 根文档和分类页的目录都按思源实际排序递归展示全部子文档，包含文章、普通文档和未标记为分类的中间层。📚 加粗标题表示分类页或带受管目录的索引页，📄 普通标题表示内容页，点击原生动态块引用可打开文档。“说明”分为 8 条短指引，介绍目录、分类、保存和编辑方法。文档新建、删除、改名、移动时自动更新受管目录；介绍等其他内容不参与重写。文章保存成功但目录失败时，可单独点击“重试目录”。插件关闭期间的变化会在重新启用后同步。
- 带受管目录的分类索引页默认使用思源的文档锁设为只读，文章保持可编辑。目录实时刷新后会重新保护新插入的文字块，避免界面显示锁定却仍可删改。需要修改分类介绍时，从文档菜单“解锁编辑”；目录刷新会保留你明确设置的解锁状态，锁定时也能自动更新目录。
- 分类无匹配、置信度不足或分类服务失败时，文章保存在锚点根下的独立文档中，并显示原因。不同笔记本以及锚点之外的分类不会参与选择。
- 同一来源再次保存会更新原文章文档，即使标题或模型分类判断发生变化也不会另建副本；不同来源的同名文章会使用独立名称，既有同名笔记不会被覆盖。先前版本未带来源标记的文档也会保留。
- 锚点按稳定 ID 定位，改名不会使分类失效；每次保存重新读取规则，并在模型返回和正式写入前核验变化。期间删除、移动或修改分类会重新决策；根文档已删除或规则持续变化时停止保存并保留草稿。删除分类标记意味着该文档不再作为候选，不能阻止用户主动修改结构。

目录的递归枚举和动态块引用机制参考 [思源目录插件](https://github.com/Szerelem0617/siyuan-plugins-index)，增删移动的实时同步由知流自行监听内核事件完成；无需安装目录插件作为运行依赖。

视角和文章格式仅在点击“AI 审阅”时使用；抓取后也可直接保存原文。“基于原文”和“小白视角”为内置视角，只读且不可删除；需要调整时，可新增自定义视角。

审阅中的图片和链接地址由插件保管，模型仅处理引用编号。异常引用最多进行 3 次局部修复，会产生额外的短文本请求，不会重新审阅全文。仍无法确认时保留审阅文字稿并标记待确认位置，原图保留在素材与历史中；进入原生编辑后，可将素材拖到目标位置，或先在正文放置光标再点击“插入光标位置”。这类审阅稿需确认后手动保存。

输出语言仅在工作台选择：默认“跟随思源界面”，也可选择“保持原文语言”“简体中文”或“英文”。选择只影响当前文章，并随历史记录保留；新文章重新默认跟随思源界面，空白工作台也可先选语言再抓取。模型设置支持多个命名的自定义供应商，分别保存密钥和模型；内置供应商不可删除，自定义供应商可重命名或删除。

设置标题右侧的“保存”始终可见，点击后留在设置页；显示“已保存”后可点击右上角“返回工作台”。空白 API Key 默认明文输入，已有密钥默认隐藏，可通过眼睛按钮切换。

供应商列表支持拖动排序，点击“保存”后记住顺序；选中列表项后也可用 Alt/Option + ↑/↓ 调整位置。

“确定”用于保留弹窗中的编辑。手动模式下，点击“保存文章”才写入思源；新文章不沿用手动目标，修改后再次保存仍然追加。自动模式沿用锚点与目录偏好，每篇文章独立保留实际保存位置；审阅后的再次修改可点击“保存文章”更新原文档。知流不创建额外草稿笔记或笔记本。

版本变化见[更新记录](https://github.com/BorisZhangYYY/noosphere-siyuan/blob/main/CHANGELOG.md)。

## 安装与环境

- 最低版本：**思源笔记 3.8.6**。
- 声明适用：Windows、macOS、Linux 桌面端及独立窗口，Docker 或其他后端的桌面浏览器前端。移动端和思源发布服务页面不在适用范围内。

## 服务与数据

抓取时，网页链接会发送给 Firecrawl，由其访问原网页。启用 AI 审阅时，待处理正文会发送给你配置的文字模型；自动分类还会向该模型发送锚点下的分类路径、介绍和文章节选；启用图片审阅时，配图和文章摘要会发送给配置的识图模型。外部服务的费用与额度以各供应商说明为准。

设置、API Key 和文章记录保存在当前思源工作空间的插件存储中；保存后的正文和已下载图片位于思源文档与资源目录。关闭窗口、禁用或升级插件会保留文章记录。
