# 知流 · ZhiLiu for SiYuan

[English](.docs/README.en.md)

在思源笔记中抓取网页文章，按需进行 AI 审阅、原生编辑与自动分类，保存正文、来源和图片。

## 可以做什么

- **网页抓取**：提取文章正文、配图及作者、发布时间等来源信息。
- **审阅与编辑**：选择 AI 审阅视角、语言和格式，或直接用思源原生编辑器整理原文。
- **配图管理**：支持 AI 图片筛选、手动增删，保存时尝试将图片下载到思源资源目录。
- **自动分类**：按分类名称、路径与描述归档文章，支持多级分类和目录自动更新。
- **历史记录**：保留原文、处理稿和保存位置，随时搜索、继续编辑或打开已保存文档。

## 开始使用

![知流工作台：顶部抓取链接，左侧编辑正文，右侧审阅、管理素材与保存](https://raw.githubusercontent.com/BorisZhangYYY/noosphere-siyuan/main/.docs/images/workbench.png)

1. 安装并启用插件，点击思源顶部的地球图标打开知流。
2. 在右上角“设置”中填写 **Firecrawl API Key**；需要 AI 功能时，再配置文字模型和可选的识图模型。
3. 粘贴网页链接，点击“抓取文章”。需要修改正文时，点击“编辑”，完成后点击“确定”。
4. 按需选择审阅视角、输出语言和文章格式，点击“AI 审阅”；也可直接保存原文。
5. 在“保存位置”选择“手动指定”，填入从思源文档菜单复制的**文档 ID**，点击“保存文章”。需要自动归档时，按下方步骤配置。

## AI 自动分类

先建立分类，再让知流根据分类名称、完整路径和描述，将审阅后的文章保存到合适的分类下。

![知流分类配置：设置根目录、开启目录维护，并管理分类名称与描述](https://raw.githubusercontent.com/BorisZhangYYY/noosphere-siyuan/main/.docs/images/classify.png)

1. 打开工作台最右侧的“分类配置”，填写**笔记本 ID 或根文档 ID**，按需勾选“自动创建并维护分类目录”，点击“保存”。
2. 在“分类管理”中点击“新增分类”，填写名称、父分类和描述，再点击“新建并同步”。描述可手写或由 AI 生成，确认同步后才写入思源。
3. 返回“当前文章”，将保存方式切换为“自动分类”，再点击“AI 审阅”。正文与图片审阅完成后会自动归档，无需再次点击保存。

分类描述用于说明收录范围，可在分类管理或思源文档中修改，下次分类即生效。分类仅在所选根目录内进行；没有合适分类或分类服务失败时，文章保存到根目录下并显示原因。

开启目录维护后，分类页会展示可点击的多级目录，并随文档新建、改名、移动或删除自动更新。分类索引页默认锁定，需要直接编辑时可从思源文档菜单解锁；文章仍可正常编辑。

## 使用说明

- **审阅与语言**：支持跟随思源界面、保持原文、简体中文或英文。内置视角只读，可新增自定义视角。
- **配图操作**：只读时单击预览；编辑时单击多选、双击预览，使用“添加”“移除”调整正文配图。移除后原图仍保留，下载失败的图片保留原链接。
- **手动保存**：“确定”只保留编辑，点击“保存文章”才写入思源。保存到已有文档时追加内容，保存到空白未命名文档时自动设置标题。
- **自动保存**：同一来源再次保存会更新原文章，不重复创建。取消或审阅失败时不自动保存；保存失败会保留审阅稿供重试。图片或链接标记为待确认时，需检查后手动保存。
- **历史记录**：关闭窗口、禁用或升级插件会保留记录；思源文档被删除后，历史中的文章仍可重新保存。

版本变化见[更新记录](https://github.com/BorisZhangYYY/noosphere-siyuan/blob/main/CHANGELOG.md)。

## 安装与环境

需要 **思源笔记 3.8.6 或更新版本**，支持 Windows、macOS、Linux 桌面端及桌面浏览器前端（含 Docker 部署）。暂不支持移动端和思源发布服务页面。

## 服务与数据

网页抓取使用 Firecrawl；AI 审阅、分类和图片筛选使用你配置的模型服务，费用与额度由服务商决定。网页链接、待处理正文、分类信息或图片会按所用功能发送给对应服务。

设置、API Key 和文章记录保存在当前思源工作空间的插件存储中；保存后的正文与已下载图片存放在思源文档和资源目录。
